# KidKinder - Kids Education Website

A responsive kids education and learning center website developed as part of my
SevenMentor Java Full Stack Development course assignment.

## 📌 Project Overview

KidKinder is a responsive educational website designed for a kids learning
center. The website provides information about classes, teachers, facilities,
testimonials, blog articles and seat booking.

## ✨ Features

- Responsive navigation bar
- Hero section
- Kids learning center introduction
- Educational services section
- About school section
- Popular classes
- Class details and tuition information
- Seat booking form
- Teachers section
- Parent testimonials
- Latest blog/articles section
- Newsletter section
- Responsive footer
- Mobile, tablet and desktop layouts

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- Responsive Web Design
- Media Queries

## 📱 Responsive Design

The website is designed to work across:

- Mobile devices
- Tablets
- Laptops
- Desktop screens
